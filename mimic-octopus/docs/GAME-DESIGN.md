# ゲーム仕様 — ミミックオクトパス v0.1

## プレイヤー体験

プレイヤーはデジタル空間に紛れ込んだ小さなミミックオクトパスです。周囲の正常データが変化したら、スマホで色・形・リズムを合わせ、監視ドローンの目をやり過ごします。

目標は90秒間の生存。「周囲を見る → 変化に気づく → 慌てて合わせる → スキャンをやり過ごす」を繰り返します。見た目のかわいさ、変形する手触り、観察が間に合った安心感を中心にします。

本書はv0.1の実装仕様です。最終QAはREADMEの確認状況を参照してください。更新時刻、反応猶予、許容差、得点などの実際の数値は `dist/js/engine.mjs` を正本とします。

## 3種類の擬態

| 要素 | 選択・学習 | 周囲で読み取るもの |
| --- | --- | --- |
| 色 | 黄・青・紫・ピンクの4色 | 近くの正常データの主な色 |
| 形 | 丸・四角・カプセルの3種類 | 周囲の輪郭 |
| リズム | 2タップから間隔と拍の位置を学習 | 周囲のバウンド、脈動、足元の光 |

色はタップで選択。形はスワイプと直接選択を用意し、意図した輪郭へすぐ移れるようにします。

リズムは1回目のタップで聞き取りを開始し、2回目で周期とタイミングを決めます。覚えた動きは自動的に続きます。プレイヤーは色と形の調整に手を戻せます。リズムが変わったら、再び2回タップして覚え直します。

テンポだけでなく拍の位置も判定しますが、厳密な一致は要求しません。許容範囲を設け、聞き取り中、一致、ずれ、入力が短すぎるなどの状態を画面で伝えます。音を消していても、周りの動きで合わせられる設計です。

初期の周囲は黄・四角・900ms周期。タコは黄・四角から始まり、リズムはプレイヤーが覚えさせます。

## 環境更新と反応猶予

90秒の中で、あらかじめ用意した環境更新が順番に起きます。通常は1〜2要素を変え、終盤に3要素を同時に変える山場を設けます。

更新時には、光の波、周囲の変形、短い通知で変化を伝えます。更新後に合わせ直す時間を設け、次のスキャンまでの残り時間を見せます。環境が変わった瞬間に、猶予のない失敗を発生させないことを重視します。

変わっていない要素はそのまま利用できます。たとえば色だけが更新された場合、正しく覚えたリズムを打ち直す必要はありません。

## スキャンと疑われ度

監視ドローンが定期的にスキャンします。スキャン中に色・形・リズムが周囲と違っていると疑われ度が上がります。一致状態には疑われ度を回復する機会を設けます。

一度の小さなミスで即終了にせず、危険が積み重なっていることをゲージ、タコの表情、スキャンの演出で理解できるようにします。判定と演出は同じゲーム状態を使います。

| 結果 | 条件と表示 |
| --- | --- |
| 成功 | 見つからずに90秒間を生存。スコアやスキャンをやり過ごした回数を結果として表示 |
| 失敗 | 疑われ度が上限に到達。主にずれていた要素を伝える |
| 再挑戦 | 時計、環境、疑われ度、リズム学習を初期状態へ戻して再開 |

結果では「色を直すのが遅かった」「拍が周囲とずれていた」のように、次回に使える振り返りを優先します。実際のセキュリティ診断や技術評価を行ったような説明は付けません。

## 状態と時間

状態は準備、プレイ中、一時停止、成功、失敗に分けます。一時停止中は環境更新、スキャン、拍の学習・再生に使うゲーム時間を進めません。

ゲームロジックは描画フレームから分離します。長いフレーム更新でも、途中にあるイベントや勝敗を順に処理します。無操作なら失敗し、適切に追従する操作なら成功できることをロジックのテストで確認します。

## 画面と操作の成立条件

- スマホの縦画面・横画面で、主役と周囲の見本、疑われ度、次のスキャン、3つの操作が読めること。
- 色と形は視覚的な直接選択を残すこと。スワイプだけを唯一の方法にしないこと。
- 周囲と自分の拍が見比べられ、2タップ後の自動継続が分かること。
- 音は任意。開始、一時停止、再開、再挑戦をタッチだけで行えること。
- ゲーム内の色・形・拍と、UIが表示する一致状態が矛盾しないこと。

## 継続開発の順番

1. ソロの見た目と変形を磨く。主役の存在感と、周囲の変化の読みやすさを揃える。
2. プレイして、反応猶予、疑われ度の増減、リズム許容差、操作範囲を調整する。
3. ソロが成立した後、共通画面とスマホの役割分担を設計する。
4. ルーム参加、複数人の状態同期、遅延、再接続を実装する。

v0.1はスマホ1台のソロです。「手元のスマホで操作し、別の画面でゲームを見る」構成には、1人用でも通信と接続管理が必要です。複数人化の仕様を、現在のソロがすでに備えているものとして扱わないでください。
