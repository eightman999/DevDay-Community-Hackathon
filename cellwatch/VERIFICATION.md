## 自動検証

Node.js v24.19.0で、以下のコマンドを `cellwatch/` 内から実行しました。npmが利用できる環境では `npm run check` と `npm test` も同じ対象を実行します。依存インストールは不要です。

```sh
node --check dist/app.mjs
node --check dist/engine.mjs
node --check dist/automata.mjs
node --test engine.test.mjs automata.test.mjs ui-wiring.test.mjs review-evidence.test.mjs
```

結果: 構文検査成功。テストランナー集計8件成功・0件失敗。これは既存の3ファイル単位のテストと、新規の名前付き5テストの合計です。画面上の8操作を確認したという意味ではありません。

| 対象 | 確認内容 | 根拠 |
| --- | --- | --- |
| 120秒の進行 | 16申請、正しい判断で保全率100・信頼100、終了状態 | `engine.test.mjs`、`review-evidence.test.mjs` |
| ゲームの葛藤 | 全件拒否は保全率100・信頼36。正常な8申請を止めると信頼を失う | `review-evidence.test.mjs` |
| 境界の判断 | 通信量20は承認、21は拒否。社内資料→外部は拒否、社内→社内と公開→外部は承認 | `review-evidence.test.mjs` |
| 見落としと対処 | 最初の誤承認で保全率94、継続被害、修復・自動拒否、隔離の時間・コスト・回数制限 | `engine.test.mjs`、`review-evidence.test.mjs` |
| 自己複製 | 12世代で核2個、36世代で4個、鏡像・前駆体・境界・停止と修復 | `automata.test.mjs` |
| 正解と解説 | 全16申請の判定整合、教科書の現在申請・理由・履歴 | `automata.test.mjs`、`ui-wiring.test.mjs` |
| UI接続 | 開始・承認・修復・教科書・実験台・再開・リセットの接続 | `ui-wiring.test.mjs`。DOMスタブであり実ブラウザではない |
