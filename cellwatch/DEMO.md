# CELLWATCH — 現行試作の確認デモ

画面・操作名・数値は現行試作を確認するための手順です。企画の要件は[コンセプト](CONCEPT.md)を参照してください。病院ステージのデモではありません。

[公開ゲーム](https://cellwatch-inspection.eightman.chatgpt.site/)を開く。ログイン・APIキーは不要。画面が狭い場合、申請書は「申請書」タブで確認します。各ケースは「↺」でリセットしてから始めてください。

## A. 遊びと学びを最短で確認

1. 「当直開始」を押す。最初の申請 #001 は本人 AOI、鍵の送信先 UNKNOWN。
2. 「教科書」を開く。当直が止まり、「今回の答え合わせ」で拒否とその理由が読める。
3. 「盤面に戻る」を押し、#001を拒否。保全率100・信頼100を維持する。操作まで14秒以上進むと自動通過するため、再試行はリセットから。
4. 次の #002 は REN → REN。承認すると正常な通信を守れる。正常な申請まで拒否すると信頼が8下がる。

## B. 見落としと対処を体験

1. リセットして開始し、#001をすぐ承認。保全率が100から94へ下がり、本人確認に侵入が発生する。
2. 本人確認を選択して「隔離」。信頼が4下がる代わりに8秒間、当該領域の被害と複製が停止する。他領域の申請は続く。
3. 本人確認を選択して「修復」。10秒後、本人確認の脅威が消え、防壁状態になる。作業中は隔離終了後の被害が続き得る。
4. 教科書の「対処の使い分け」で、拒否・隔離・修復の違いを読む。修復しても失った保全率・信頼は戻らない。

## C. 自己複製を短時間で確認

開始前でも「教科書」を開けます。「03 自己複製」の実験台で「初期配置へ」を押し、以下を確認します。

| 操作 | 期待表示 |
| --- | --- |
| 初期配置へ | 世代 0 / 生存セル 12 |
| +12世代を1回 | 世代 12 / 生存セル 24 |
| さらに+12世代を2回 | 世代 36 / 生存セル 48 |

生存セル数だけでなく、核の配置が2個・4個になることを `automata.test.mjs` でも検証しています。HighLifeそのものは既存のセルオートマトンです。

## D. 120秒の完走を確認

毎回、申請書に書かれた条件で判断。最初から順に **拒否・承認・拒否・承認** を4回繰り返すと全16件に正解します。修復・隔離は不要。保全率100・信頼100で終了し、結果から教科書に進めます。答えを覚えることより、二つの欄を照合する体験が学習の対象です。

Canvasを操作できない閲覧環境では、[作品概要](REVIEW.md)と[検証記録](VERIFICATION.md)から設計と再現方法を確認できます。画像だけで動作確認済みとは扱わないでください。
