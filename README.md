# CELLWATCH — 病院を守る120秒

**通信審査 × 自己複製するセル × 適応する出題。病院のデータを通すか止めるか、120秒で判断するブラウザゲームです。**

あなたは病院の通信審査担当。受付・電子カルテ・検査・予約の申請書を読み、6項目の証拠と規則から通過／遮断を決めます。不正を見逃すとセルが自己複製し、模擬カルテに被害が出ます。正常な通信を止めても診療予約が延期されます。「全部遮断する」だけでは病院を守れません。

![CELLWATCHの通信審査画面](docs/images/cellwatch-review.png)

現行ソースは **v0.3.1の審査改善版**です。[既存の公開デモ](https://cellwatch-inspection.eightman.chatgpt.site/)は旧版で、このブランチの修正はまだ同期していません。以下の機能を確認する場合はローカルで起動してください。

## 体験の特徴

| 仕組み | プレイヤーが確かめられること |
| --- | --- |
| 単語の一致だけでは決まらない6項目 | 同じ正常な技術所見でも、主体不一致・権限外操作・情報区分と宛先の組合せ・展開後の容量で可否が変わる。確認チェックはメモで、正解を教えない |
| 業務を止める代償 | 不正の見逃しだけでなく、正常通信の誤遮断・隔離にも予約延期が生じる |
| 判断結果とセル盤面の接続 | 外部→審査ゲート→病院へ進む同じ伝票を追い、誤許可した通信から実際のHighLifeが進行する |
| 適応型と固定練習 | 適応型は直近の判断・防御状態と実行ごとのseedで候補を選ぶ。顔は正誤と独立に割り当て、テンプレート番号を審査画面に出さない。CSV順は16件を再現して比較するための練習用 |
| 共通の判定規則 | 画面・採点・判定後の理由・教科書が同じ6項目を使い、答えは判定後に確認できる |

### 遮断・隔離・根本修復の違い

| 操作 | 対象と効果 | 代償・限界 |
| --- | --- | --- |
| 遮断 | その通信1件の通過を止める | 既存の侵入は残る。正常通信なら予約8件を延期 |
| 一時隔離 | 選んだ領域の複製・継続被害・審査期限を8秒止める | 予約4件を延期。当直中2回。解除後は再開 |
| 根本修復 | 10秒後に領域の侵入を除去し、待機中・以後の不正通信を自動拒否 | 同時に1領域。修復中は被害が続き、既存被害は回復しない |

## 3分で確かめる

ローカル起動後、PCブラウザで操作します。以下は発表・比較用に再現できる **CSV順（練習）** のデモです。目安は説明を含む実時間です。**各申請の到着直後に一時停止して読み、再開して判定**すれば、28秒の期限内に操作できます。初見では先に「時計なし演習」を選び、1件ずつ判定理由を読んで「次の演習へ」で進むこともできます。隔離・根本修復は120秒の当直で試します。

| 目安 | 操作 | 見るポイント |
| --- | --- | --- |
| 0:00–0:35 | 「敵の動作」を「CSV順（練習）」にして当直開始。ゲーム内0秒の受付通信で一時停止し、6項目を照合。再開して「遮断する」 | 技術所見の違反と、判定後の理由。その1件を止めても受付は修復済みにならない |
| 0:35–1:10 | ゲーム内7秒の電子カルテ通信、14秒の検査通信の到着時にそれぞれ一時停止して照合。前者は6項目を満たすので許可。後者は違反を確認したうえで、比較のため意図的に許可する | 正常データの配送と誤許可の違い。後者だけが侵入となり、模擬被害が増える |
| 1:10–2:10 | 検査領域を選び「一時隔離」、続けて「根本修復」。ゲームを再開した状態で8秒の隔離解除と10秒後の修復完了を観察し、完了後は一時停止 | 隔離の予約延期、修復後の侵入除去、被害の累積値が戻らないこと |
| 2:10–3:00 | 「教科書」で判定履歴を確認し、自己複製の実験台を初期配置へ戻す。「+12世代」を1回、さらに2回押す | 12世代で核2個・24セル、36世代で核4個・48セル。セル数は模擬被害件数ではない |

当直を最後まで進めると報告書で被害と領域別の判断を確認できます。再挑戦では適応型に切り替え、同じ伝票順の暗記に頼らず証拠を読みます。

## 起動と検証

Node.js 22.9以降が必要です。**Windows / Node.js 24.17.0で動作確認**しています。追加パッケージのインストール、ビルド、アカウント、APIキーは不要です。リポジトリのルートで実行します。

```powershell
npm run dev
```

[ローカル端末](http://127.0.0.1:8766/)を開きます。サーバーは127.0.0.1のみで待ち受けます。ポートが使用中なら別ポートを指定します。

```powershell
$env:CELLWATCH_PORT = '8767'
npm run dev
```

自動検証:

```powershell
npm run check
npm test
```

`check`はJavaScriptの構文検査です。自動テストは90件成功（2026-10-18）。CSV整合性、6項目の採点と理由、固定順／適応型の完走、時計なし演習の手動進行、被害・隔離・修復、HighLifeの12/36世代、盤面と申請IDの対応、APIのモックとローカルHTTP経路、期限超過・遅着・重複・予算を検証しています。DOMスタブによる接続テストは、実ブラウザや人間による使いやすさ評価とは区別しています。

実ブラウザでの確認範囲と再現条件は[検証記録](docs/validation.md)、機械比較の実測値は[結果JSON](docs/evidence/review-metrics.json)を参照してください。

出題を番号だけで攻略できないことと、画面の証拠で正解できることを比較する再現用スクリプトもあります。

```powershell
node scripts/verify-demo.mjs
```

seed 1〜128、各16件（各bot 2,048件）のローカル適応型で、旧来の番号周期だけを使うbotは正答55.47%、公開された6項目規則を完全に実行するbotは100%・被害0・未審査0でした。16人すべてのキャラクターで正常・不正の両方を確認しています。同じseedでも判断履歴により後続の出題は変わります。これは規則と出題を検証する比較です。

## DevDay機能：実装したこと、実際に確認したこと

Decisions APIの役割は、プレイヤーの直近の判断と防御状態を見て、**次に届く模擬通信を既知のCSV候補から1件選ぶこと**です。採点や安全条件をAIの回答で変えずに、出題の選択へ使います。[OpenAI公式仕様](https://developers.openai.com/api/docs/guides/decisions)の`POST /v1/decisions`・`gpt-6-luna`・`choice`に対応しています（2026-10-18確認）。

| 要素 | 実装・記録 | 確認済みの範囲 |
| --- | --- | --- |
| Decisions API連携 | サーバーから候補選択、応答検証、期限・呼出上限、ローカル切替を実装 | モック応答と実HTTPのローカル経路まで。**実APIの課金呼出は未実施** |
| APIなしの適応型 | ローカルで判断履歴・防御状態を参照 | キー未設定でもゲーム・採点・教科書を実行可能。APIルートのない静的配信でもこちらへ切替 |
| キャラクター画像 | GPT Imageで生成した16枚を同梱。生成プロンプトは[記録](artifacts/hospital-character-prompts.json)に保存 | ゲーム実行時の画像生成API呼出は不要。顔は正解条件に使わない |

任意でAPIを使う場合は、[`.env.example`](.env.example)を参考にローカルの`.env`へ`OPENAI_API_KEY`を設定し、サーバーを再起動します。キーはGit対象外・サーバー側のみで扱います。

| 設定 | 動作 |
| --- | --- |
| `CELLWATCH_ENEMY_MODE=auto` | キーがあればDecisions、なければローカル（既定） |
| `CELLWATCH_ENEMY_MODE=local` | キーがあってもAPIを呼ばない |
| `CELLWATCH_ENEMY_MODE=decisions` | Decisionsを優先。未設定・失敗・遅延時はローカル |
| `CELLWATCH_PORT=8766` | ローカル待受ポート。未指定時は`PORT`も参照 |

APIへ渡すのはラウンド・seed・4領域の防御状態・直近24件までの判断と、CSV由来の候補説明です。初手はローカル、以後は投入2秒前に先読みし、期限超過や不正応答でも出題を待たせません。呼出上限・期限・入力検証の詳細は[仕様書](spec.md#9-適応型とdecisions-api)にまとめています。

## 教材としての範囲と制約

- **病院を題材にした仮想モデル。** 2017年のWannaCryによるNHSの診療への影響が背景です。WannaCryと結び付けるのはSMBの例だけで、他10種類は仮想例です。史実と教材の対応・公式資料は[教科書](textbook.md)に分けています。
- **セルの自己複製は実計算、被害は別のゲームモデル。** HighLife（B36/S23）の隣接規則で更新します。被害は侵入件数・経過時間から算出し、生存セル数には比例しません。カルテ／予約各100件は模擬母数で、被害種別間には重複があります。
- **実攻撃・患者データ・認証・DBは扱いません。** 模擬通信と所見のみを使い、状態はメモリ内です。再読み込み・リセットで消えます。10秒の修復は複数対策をまとめた演習の抽象です。
- **検証範囲。** 実APIの利用権限・遅延・出題品質、人間ユーザーによる初見操作、スマートフォン実機・他ブラウザ比較は未検証です。botの実測は人間の学習効果を示しません。
- **公開版との違い。** 既存Sitesは旧版です。現在の接続アカウントでは既存サイトIDの取得が`404 project_not_found`となり、今回の同期・公開は未実施です。既存サイトへのアクセス権の確認が必要で、現行ブランチの動作証拠には使いません。
