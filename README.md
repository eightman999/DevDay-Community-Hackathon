## 今回使う新機能

DevDay 2026のWebsite annotationsで、その瞬間のゲーム状態をChatGPTへの攻略相談に添付します。周期・位相差まで記録できるため、画像だけでは説明しにくいリズムのずれを伝えられます。
ゲーム本体の判定は固定ロジックです。ゲーム内でAIモデルを動かしているという主張はしません。
