# CELLWATCH — 通信審査局

4種類の攻撃パターンが動くセル状のダッシュボードと、通す／止める審査デスクを連動させた、120秒のブラウザゲーム。
旧PATCH / PANICとは別のSitesとして公開するモックです。

## 遊び方

当直を開始し、左側の伝票の「通過条件」と2つの欄を照合します。
正常な通信を通すと緑の流れに戻り、不正な通信を通すと赤い侵食が始まります。
中央の領域を選ぶと、その領域の伝票を絞れます。遮断は1件だけを止め、根本修正はその後の不正な通信も自動で止めます。
審査猶予14秒、伝票は7秒おき、根本修正10秒・同時に1領域。未審査は自動通過します。
一時停止、操作ガイド、再挑戦、当直報告書があります。狭い画面では盤面・審査机をタブで切り替えます。

## 攻撃の表現

- 本人確認：斜めに移動する小さな塊
- 共有領域：枝分かれする侵食
- 入口：押し寄せる波
- データ出口：外へ抜ける粒

正常な背景はB3/S23のライフゲーム。攻撃の形は判断を視覚化するゲーム用の比喩で、現実の攻撃手順の再現ではありません。

## 開発

依存パッケージとビルド工程は不要。ES Modulesを使うためHTTPで配信してください。

```sh
python3 -m http.server 8766 --bind 127.0.0.1 --directory dist
node --check dist/app.mjs
node engine.test.mjs
```

画面のフォントはGoogle Fonts。取得できない場合はシステムフォントで表示します。

## 監視卓UI

中央は96×60セルの連続した一枚の盤面。左に紙の申請書・チェックリスト・メモ、右に脅威レベル・履歴・未対応一覧、下に調査・隔離・承認・拒否・修復。領域のラベルまたは盤面の位置を選ぶと申請書を絞れます。

隔離は8秒間その領域の継続被害と審査期限を止めます。信頼を4消費し、当直中2回まで。根本修復と組み合わせて使います。
