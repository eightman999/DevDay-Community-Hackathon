# CELLWATCH — 夜間システム監視局

[公開ゲーム](https://cellwatch-inspection.eightman.chatgpt.site/)

中央の連続セル盤面を監視し、左の紙の申請書を照合して承認・拒否する120秒ゲーム。旧PATCH / PANICとは別モックです。

背景はライフゲーム（B3/S23）、脅威は実際に自己複製するHighLife（B36/S23）。4領域で核の配置・向き・更新速度を変えています。隔離は8秒、根本修復は10秒。教科書には申請ごとの正解と理由、自己複製実験台があります。

## 開発

Node.jsとPython 3を使用。npm依存のインストールとビルドは不要です。

```sh
npm run dev
npm run check
npm test
```

ローカルURL: http://127.0.0.1:8766/

## 文書

- [仕様書](spec.md): 画面、当直、審査条件、得点、セル規則、検証条件。
- [教科書](textbook.md): 承認/拒否の基準、対処の違い、自己複製の解説。
- Sitesの公開識別子は `.openai/hosting.json` に保持。更新時に新規Siteを作らないでください。

## 検証

ゲームの完走、審査、被害、隔離、修復、正解整合、12/36世代の自己複製、DOMスタブでの画面接続・教科書を検証しています。実ブラウザでの表示と実機レスポンシブ確認は未実施です。

状態はメモリ内のみ。フォントはGoogle Fontsから読み込み、取得できない場合はシステムフォントで表示します。
