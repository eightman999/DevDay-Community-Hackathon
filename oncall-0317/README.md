# 03:17 — ON CALL

**公開デモ / 2026年10月18日**

[Sitesで遊ぶ](https://oncall-0317-prototype.eightman.chatgpt.site) — 静的デモ版。自由記述はローカル判定で、AI未使用です。

深夜の緊急電話から始まる、13歳以上を対象とするサイバーセキュリティ教育タワーディフェンス**風**ブラウザゲーム。1プレイ約120秒、3局面の意思決定を経験し、最後に実在するCVEと比較した事後報告書を確認できます。

> **重要：これは大会の提出済み成果物ではありません。** 元のZIPは検討用の非公開試作として作成され、その後Sitesにデモを公開しました。大会の「事前制作はプロトタイピングに限る」ルールの適否は主催者確認が必要です。

## 今すぐ遊ぶ（APIキー不要）

**方法 A：最短で試す** — `standalone-preview.html` をブラウザで開く。ダウンロード済みフォルダから直接動きます。自由記述は**ローカルの簡易キーワード分類で、AIではありません**。

**方法 B：Node.js 18以上でサーバー起動**

```bash
npm start
# http://127.0.0.1:4173 を開く
```

依存パッケージのインストールは不要。ゲームの全部の場面を API キーなしで遊べます。通信が必要な本番の脆弱性スキャンは行いません。

## ルールと操作

1. 「電話に出て、対応する」で通常の120秒モード開始（時間制限なしの学習モードもあります）。
2. 建物をクリックして解説を読む。右側から毎局面の対応を1つ選び、サービス状態の変化を確認する。
3. 自分の言葉で提案する場合はテキスト入力→「判定」→分類候補を確認→「実行」。
4. 3局面終了または時間切れで報告書に遷移。印刷 / PDF保存、再プレイも可能。

## 本物のDecisions APIを使う場合（要APIキー・課金）

```bash
OPENAI_API_KEY='YOUR_KEY_FROM_ENV' ENABLE_DECISIONS_API=1 npm start
```

`OPENAI_API_KEY` はシェル環境変数のみに設定。**ブラウザやGitに入れないこと。**

サーバーで `POST /v1/decisions` を呼び出し、`gpt-6-luna` の `choice` と `predicate` により自由記述を分類します。低信頼度や不明確な指示は実行しません。実装は `decision.mjs` と `server.mjs`。

- `GET /api/status`：API の有効/無効状態。
- `POST /api/evaluate`：`{ "text": "サーバー側で権限を確認する", "stage": 1 }`。
- オフライン時のレスポンス `mode: offline`。実APIの成功時は `mode: live`。
- APIが失敗した場合は **AI未使用のローカル判定**へ切り替えることを明示します。
- **外部APIへの接続試験は未実施**。アクセス権と課金、APIの最新仕様を会場で確認してください。

## 技術・安全上の注意

- サンプルは架空のHARBORサービス。**実際のサイトを攻撃・検査していません**。
- `DATA AT RISK` 等はゲーム内の仮想メトリクスで、実際の流出確率を示しません。
- CVE-2023-22515はConfluenceのアクセス制御の実例で、このシナリオの再現ではありません。
- APIに送信されるのはユーザーが入力した自由記述案のみ。個人情報・実システムの秘密を入力しないでください。
- 本番運用では認証、レート制限、サーバレス化、監視、アクセシビリティテスト、費用上限などが追加で必要です。
- Google Fontsは任意。ネット未接続時はシステムフォントへフォールバックします。
