# BEAT BORDER — 拍で、見抜け。

[30秒の試遊版](https://mimic-octopus-1018.morita-shibu5.chatgpt.site/beat-border/)

大きなドット絵のデータを読み、白いノーツが中央のひし形に重なった瞬間に、許可・拒否・保留を押すリズム検査ゲームです。120 BPM、12件、30秒。←/↓/→、A/S/D、画面の3ボタンに対応します。

| 条件 | 判断 |
| --- | --- |
| 個人の電話番号・住所・メールを含む | 拒否 |
| 中身が暗号化されて読めない | 保留 |
| それ以外 | 許可 |
| 15秒の追加通達以降、.exeを含む | 拒否 |

拒否条件を最優先します。判断の正解数と、拍のPERFECT数を別々に表示し、スコアは両方を反映します。判定窓は前後220ms。PERFECTは75ms以内、GOODは150ms以内、OKは220ms以内。1件の判定後は400msスタンプを見せてから次のデータに切り替えます。保留は暗号化データに対する正解で、追加検査を実行する機能はまだありません。

ドット絵6種類と音楽はコードで生成したオリジナルです。外部アセット・ライブラリへの依存はありません。出題はすべて架空のデータと連絡先です。

## 起動と検証

このフォルダを静的HTTPサーバーで配信してください。ビルドは不要です。

```sh
python3 -m http.server 4173
# http://localhost:4173 を開く
node --test tests/*.test.mjs
```

- `index.html` / `style.css`：開始・検査・一時停止・結果の画面、縦横のレイアウト。
- `engine.mjs`：時刻、固定出題と規則、入力窓、採点。一時停止と再挑戦。
- `sprites.mjs`：Canvasのドット絵。
- `audio.mjs`：Web Audioの音楽と判定音。
- `app.mjs`：入力、描画、サウンド、結果の振り返り。

2026-10-18確認：このゲームの6テスト、既存ゲームを含む24テストと静的チェックが通過。全問正解1200点、無操作で12件MISS、判定窓、規則の優先順位、後半の追加通達、一時停止・再開、連続入力、再挑戦を検証しました。Codex内ブラウザの1280×720、iframe内390×844・844×390で表示を確認。入力による加点、停止中の時計維持、通達、結果と全件の理由を確認しました。物理スマホでの指の操作と、実際に聞こえる音は未確認です。

## DevDay機能の現在地

Sitesで公開するブラウザゲームです。現在は固定の出題とルールで動作します。**Decisions API / Sites MCP は未接続**で、画面の「この試作について」にも明記しています。

今後の構想は、Sites MCPから次のステージの規則を変更し、Decisions APIがデータと規則から正解と理由を事前判定することです。音の再生・拍の入力判定をブラウザで行い、プレイ中にAPI応答を待たない構成を想定しています。これらはまだ実装済みの機能ではありません。
